Helpdesk API v1

PHP 8.2 · MySQL 8 · JWT
Sistema operacional · http://localhost:8080

Autenticação

POST /api/v1/auth/login público Gera JWT
POST /api/v1/auth/logout auth Revoga token
GET /api/v1/auth/me auth Usuário + RBAC

Tickets

GET /api/v1/tickets tickets.view Listar com filtros
POST /api/v1/tickets tickets.create Criar ticket
GET /api/v1/tickets/{id} tickets.view Detalhe
PATCH /api/v1/tickets/{id} tickets.edit Atualizar

Replies

GET /api/v1/tickets/{id}/replies tickets.view Listar respostas
POST /api/v1/tickets/{id}/replies tickets.create Adicionar resposta
